# 盛勇杰 · 个人作品集

React + Vite 单页个人作品集。首页使用用户提供的幻想风格背景图片，全站以浅黄纸色、复古芥末黄和深棕色构成主色，版心最大 1700px。页面包含全屏首页、个人介绍与经历、精选项目、创作能力，以及整屏联系页。

精选作品展示四部完整短片：《猫知道》（猫咖题材）、《重新认识一下》（失忆主题）、《战斗练习1》和《时尚短片》。四张封面均提取自对应原片。点击封面打开视频播放器，支持原生播放控制、音量、进度拖动与全屏；关闭或切换作品时停止播放并释放资源，切到后台时暂停。

作品列表只加载轻量 WebP 封面，选中作品后才加载对应视频。网页播放版本采用 H.264 / AAC、MP4 fast start，并保留原片 AAC 声音。四部网页视频共约 74MB，单个文件均低于 Cloudflare Pages 的 25 MiB 上限。失忆主题为 24.59MB（23.45 MiB）、1280×734、30fps，直接从原片制作，采用两遍编码、medium、目标视频码率 1.2Mbps、峰值 2.4Mbps；其他三部仍使用 CRF 23、medium、峰值 4.5Mbps，画面尺寸与帧率保持不变。四部视频均保留完整时长，原文件保持不变。浏览器限制自动播放时，可使用原生播放按钮。

背景音乐使用用户提供的《异世界生活小曲》。右下角的复古黄色控件支持播放、暂停和音量设置，默认音量 30%，循环播放。音乐在第一次点击播放时才加载，首次打开页面保持静音。约 25.8MB 的 WAV 转为约 3.2MB 的 192kbps 立体声 MP3，保留完整时长约 2 分 14 秒；原 WAV 保留在 assets/source/audio，不进入发布包。

打开作品视频时先暂停背景音乐，关闭视频后仅恢复此前正在播放的音乐；手动暂停的音乐保持暂停。切到后台或离开页面时暂停，返回后可手动继续。控件使用原生 audio，没有滚动监听、音频可视化或持续更新进度的计时器；卸载时停止声音、释放源文件并清理监听。

首页作品按钮与导航联系按钮的默认底色为 `#EDD38A`，悬浮时切换为深棕色，配合约 0.25 秒的颜色过渡；键盘聚焦也提供相同反馈，并支持系统的减少动态效果设置。首页星号与版心右边缘对齐。

## 页面动效

使用 GSAP + ScrollTrigger 编排开场与滚动序列，缓动曲线通过 CustomEase 调整。

- 首屏约 4 秒完整开场：浅黄色幕布上的个人标识进场，幕布向上揭开，背景缓慢归位；两行中文标题从遮罩内大幅位移并由压缩状态展开，随后导航、简介和按钮依次进入。
- 关于我、个人经历、精选作品、创作能力、联系页使用大号英文标题。英文单词先从遮罩内展开，中文标题与说明随后进入；经历、项目、能力卡片按列错开约 0.19 秒。
- 旅行者插画与项目封面使用遮罩揭开。桌面鼠标设备上，首屏背景与项目图片增加轻微滚动视差；图片悬浮放大作用在独立内部图层。
- 保留原生滚动。初次打开、刷新或从浏览器缓存恢复时回到首页顶部，初始章节锚点会被清除；页面内导航仍正常跳转。入场只播放一次，快速往返滚动不会重启动画；开场期间主动滚动或键盘聚焦会立即展示内容。
- 系统开启减少动态效果时恢复静态内容，偏好变化时自动清理、重建动画。组件卸载或尺寸断点变化时清理时间线与滚动触发器，临时图层提升在入场结束后移除。

主要使用位移、缩放和遮罩，没有弹跳缓动。开场结束即撤掉开场专用滚动监听；导航背景通过 IntersectionObserver 切换。图片已有固定尺寸，不再逐张加载时刷新 ScrollTrigger；字体加载后统一刷新。静态模块使用 memo，避免导航与播放器状态变化时重复构造卡片和 SVG。

动画实现参考 [GSAP matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/)、[ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) 和 [CustomEase](https://gsap.com/docs/v3/Eases/CustomEase/)。

头图下方使用用户提供的 React Bits AeroShards 组件作为背景：浅黄纸色搭配珍珠质感碎片，支持鼠标排斥、点击涟漪与长按聚拢。动效范围固定在头图下方起始处的一屏高度内（最小 600px），使用区块内的绝对定位，滚动时随所在区域离开屏幕。离开屏幕或切换页面后暂停；系统开启减少动态效果时显示静止画面。

不支持 WebGPU 或绘图初始化失败时，自动显示同色系的轻量碎片背景。兼容背景只保留缓慢漂浮效果，不提供鼠标聚拢与涟漪。项目使用 `vgpu@0.5.0` 的浏览器接口；其 Node 原生绘图模块不参与页面运行。

背景不在首屏加载 WebGPU 模块，进入其限定区域后在空闲时初始化；快速离开区域或切到后台会取消待执行加载。不支持 WebGPU、系统减少动态效果或省流量模式时使用 SVG。背景仍位于头图下方的一屏内，离屏和后台停止绘制。空闲绘制目标 30fps，交互目标 60fps，仅露出小部分时 12fps；DPR 上限 1.25，渲染像素预算约 250 万。关闭额外泛光、颗粒和色散，当前设置走单通道绘制。

教育与工作经历使用用户提供的 React Bits PixelCard 样式，呈现三张圆角卡片。悬浮或键盘聚焦时展开复古黄色的像素光点，离开后收起；进入视野才分配像素数据，每张卡最多 3000 点，按颜色批量绘制，目标 30fps，并按实际间隔保持原有播放速度。卡片离屏或页面进入后台时暂停绘制，减少动态效果模式下使用静止像素。卡片高度随内容增长，文字可选中，移动端改为单列。组件使用 Canvas 2D，无需新增依赖。页面内可通过 `#experience` 定位到该模块。

首页背景提供 960 / 1536 / 1920 / 2560 / 2912px 五档 WebP，人物插画提供 480 / 720 / 890px 三档；保留原构图和色彩，通过 srcset 按屏幕选择。1920px 头图约 431KB，720px 插画约 120KB。HTML 提前预载同一组响应式头图和开场所需字体，其他图片异步解码、延迟加载。仅分发使用的三份 Latin WOFF2 字体，字体许可保留在 public/fonts。

## 预览

本机可以双击上一级目录中的 `启动作品集.cmd`。如果预览已经在运行，它会直接打开页面。

有 Node.js 环境的电脑也可以在此目录运行：

```sh
npm install
npm run dev
```

开发地址：`http://127.0.0.1:5173/`。当前项目使用 pnpm，并附带 `pnpm-lock.yaml`；也可以使用 `pnpm install --frozen-lockfile` 和 `pnpm dev`。

```sh
npm run build
npm run preview
```

构建结果在 `dist/`。构建结束会检查所有发布文件是否符合 Cloudflare Pages 的单文件 25 MiB 限制；超限时会列出文件并停止构建。

## Cloudflare Pages 部署

本项目是 Vite 静态网站，构建命令使用 `npm run build`（或 `pnpm build`），构建输出目录为 `dist`。当前 Git 仓库根目录就是 portfolio 项目目录。

Cloudflare Pages 的[单个静态文件上限为 25 MiB](https://developers.cloudflare.com/pages/platform/limits/#file-size)，不是整个网站的总大小上限。`scripts/check-pages-assets.mjs` 会在每次构建后检查 dist 中的所有文件。原始图片、音乐与旧视频档案位于 assets/source，不进入 dist。

本地修复后，需要把修改提交并推送到已连接的 GitHub 仓库，Cloudflare 才能构建新版本。仅重试使用旧提交的部署仍会使用原来的文件。

可运行 `pnpm test:motion` 检查启动回顶、开场、页面内导航、图片延迟加载、标题与卡片顺序、重复触发、键盘聚焦、减少动态效果和清理行为。这些检查使用模拟 DOM，不代替浏览器中的视觉与帧率检查。刷新页面可重新查看完整开场。

`pnpm test:media` 检查四部作品的资源映射、MP4 完整性与 fast start、关闭后的资源释放、后台暂停和自动播放被限制时的处理。

`pnpm test:music` 检查音频资源、点击后加载、音量边界、视频播放时暂停及恢复、后台暂停、快速切换与异步播放竞争、失败重试和卸载清理。音乐与视频切换顺序也包含在 test:performance 的页面集成检查中。

`pnpm test:performance` 检查高分屏背景像素预算、预载与页面选图一致性、像素卡片按需初始化与绘制节流、导航阈值观察和视频按需加载。这些是模拟 DOM 与资源检查，不是实际浏览器帧率或 Lighthouse 测试。详细审查见 `PERFORMANCE.md`。

## 真实信息与示意素材

- 姓名、电话、邮箱、教育与工作经历来自提供的简历。短片数据按用户最新补充更新为 7 部，其中 4 部超过 1 分钟、3 部约 30 秒。
- 个人图片使用用户提供的彩色旅行者插画，完整保留原图与色彩。简历中提取的原始彩色头像仍保留为备用素材。
- 项目主题来自简历及用户提供的四部短片：猫咖、失忆、动作与时尚。未编造客户、获奖、商业合作或播放量。
- 精选作品使用真实原片与原片截图。此前由内置 ImageGen 生成的三张示意图保留为备用，不再用于精选作品卡片。
- 首页当前使用用户提供的图片作为静态全屏背景，原图与颜色完整保留。此前的示意视频仍可作为备用素材，当前不加载。
- 邮箱链接使用 `mailto:`，电话链接使用 `tel:`；复制按钮将邮箱复制到剪贴板。没有自动发信或后台表单。

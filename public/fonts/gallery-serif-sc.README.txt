Gallery Serif SC Regular
=======================

Self-hosted Chinese serif font for the portfolio's names and display headings.
This is a static weight-400 subset of the official Noto Serif SC font.
The derivative family and PostScript names are Gallery Serif SC and
GallerySerifSC-Regular. The source outline design is unchanged.

File: gallery-serif-sc-regular.woff2
Size: 92,572 bytes
Coverage: 560 encoded characters, including 455 CJK characters; 594 glyphs.
Content basis: Chinese text in src JS/JSX/TS/TSX plus the agreed gallery labels,
ASCII U+0020-U+007E, and punctuation occurring in the site text.
Verified against the current site source on 2026-10-21: no missing characters.

Source: https://github.com/google/fonts/tree/main/ofl/notoserifsc

Use through the 'Gallery Serif SC' @font-face declared in src/fonts.css.
The font may be preloaded with as="font", type="font/woff2", and crossorigin.
Use a local Songti/SimSun/serif fallback for newly added characters until the
subset is regenerated. This file is deliberately not a complete CJK font.
